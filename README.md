# Uber Pickup Clustering & Spatial Analysis 

##  Project Overview

An unsupervised machine learning project for analyzing Uber pickup patterns using clustering techniques. The project includes spatial and spatio-temporal analysis, trained machine learning pipelines, and an API for cluster prediction.

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Joblib
* FastAPI
* Streamlit
* Matplotlib
* Seaborn

##  Project Structure

* `API_main.py` — FastAPI application for cluster prediction.
* `GUI_app.py` — Graphical user interface.
* `Notebook/` — Jupyter Notebook containing the analysis.
* `Data/` — Project datasets.
* `pipeline_spatial.pkl` — Spatial prediction pipeline.
* `pipeline_temporal.pkl` — Spatio-temporal prediction pipeline.
* `requirements.txt` — Required Python dependencies.

##  Installation

Clone the repository and install the required dependencies:

```bash
pip install -r requirements.txt
```

##  Project Features

* Spatial clustering analysis.
* Spatio-temporal clustering analysis.
* Machine learning pipelines for prediction.
* FastAPI endpoints for cluster prediction.
* Data analysis and visualization.
